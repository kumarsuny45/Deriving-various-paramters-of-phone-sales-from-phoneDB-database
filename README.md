# Deriving-various-paramters-of-phone-sales-from-phoneDB-database 
Introduction -
PhoneDB website, which is the information website for smartphones, tablets, PDAs, and mobile
devices. PhoneDB offers a comprehensive collection of data and various services that harness the
potential of this valuable resource to aid users in finding the most suitable mobile device.

a1. Retrieve the model name, manufacturer, weight, price, and price currency for the
device(s) based on the oem_id.
a2. Retrieve the brand, model name, RAM capacity, market regions, and the date when
the information was added for device(s) associated with a specified code name.
a3. Retrieve the oem_id, release date, announcement date, dimensions, and device
category of the device(s) based on a specified RAM capacity.
a4. Retrieve model, width ,height, price based on device category.
b1 is top 5 regions where a specific brand of devices was sold for all manufacturers.
b2 is average price of devices within a specific brand, all in the same currency.
b3 is average mass for each manufacturer and display the list of average mass. 
b4 contains analysis for prices in descending order based on hardware designer,operating_system, ram_capacity, max_charging_power .
c1. Create a chart to visually represent the proportion of RAM types for devices in the
current market.
c2. Create a chart to visually compare the number of devices for each USB connector type
c3. Create separate charts illustrating the monthly average price trends (in GBP) for
devices released in each year from 2020 to 2023. Each chart should focus on a specific
year.
